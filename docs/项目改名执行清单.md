## 执行步骤

### 第 1 步：数据库改名（不重建容器，零数据风险）

在已有容器内直接改名：

```sql
-- 连接现有容器
docker exec -it youlai-postgres psql -U youlai -d postgres

-- 改名（需要断开所有连接）
SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname = 'youlai_admin';
ALTER DATABASE youlai_admin RENAME TO test_copilot;
ALTER ROLE youlai RENAME TO test_copilot;
ALTER ROLE test_copilot PASSWORD 'TestCopilot@2026';

-- 验证
\c test_copilot test_copilot
SELECT count(*) FROM sys_user;  -- 应返回 7
```

## 不改的内容

| 内容 | 原因 |
|------|------|
| Python `app` 包名 | 全项目 import 依赖，改了崩溃 |
| `ai_tc_` / `sys_` 表前缀 | ORM 模型和迁移脚本依赖 |
| 前端路由路径 | 用户收藏链接不失效 |
| `.env.local`（AI 配置） | 不含项目名，不需要改 |
| `skills-lock.json` | 来源是外部仓库，可不动 |

---

## 风险

| 风险 | 等级 | 说明 |
|------|------|------|
| 数据丢失 | **无** | 第 1 步用 ALTER 改名，不删数据 |
| 原项目受影响 | **无** | 操作的是副本，原项目不动 |
| venv 失效 | **低** | 第 6 步重建即可，2 分钟 |
| 文档遗漏 | **低** | 逐个文件替换，验证时检查 |
