## 更新完整 Bug‑Agent 能力清单

1. Bug 相似检索 / 重复查重（向量底座）
2. Bug 现象 → 排查线索、根因猜想列表
3. ✨**Bug 举一反三外推猜想（新增）**：提炼缺陷模式，输出其它高风险场景、测试点，可流转生成候选用例
4. Bug ↔ 用例双向闭环
   - Bug 生成 / 补充回归用例草稿
   - 用例失败匹配已有 bug
5. Bug 工单文本辅助：生成 bug 草稿、解析日志堆栈提取关键信息
6. Bug 规范审查：单条实时审查 + 批量巡检，输出质量评分、问题清单、优化建议
7. 可选低优先级：单 bug 打标签、优先级 / 责任人建议（仅输出建议，不写工单）
