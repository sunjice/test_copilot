# test-copilot 生产部署指南

## 一、架构

```
客户端 ──→ Nginx (80/443) ──┬── / → 前端静态文件
                            └── /prod-api/ → tc-api :8000
                                                  │
    ┌─────────────┬─────────┬────────┬──────────────┬──────────┐
    │             │         │        │              │          │
PostgreSQL    Redis    MinIO     Elasticsearch   Milvus    Ollama
(tc-postgres) (tc-redis) (tc-minio)  (tc-es)   (tc-milvus) (外部)
```

| 组件 | 容器 | 端口 | 说明 |
|------|------|------|------|
| Nginx | 宿主机 | 80/443 | 前端 + API 代理 |
| API | tc-api | 8000 | FastAPI |
| PostgreSQL | tc-postgres | 5432 | 数据库 |
| Redis | tc-redis | 6379 | 缓存 |
| MinIO | tc-minio | 9000/9001 | 文件存储 |
| Elasticsearch | tc-es | 9200 | 全文检索 |
| Milvus | tc-milvus | 19530 | 向量检索 |
| Ollama | 外部服务器 | 11434 | Embedding |

## 二、环境要求

- Docker 24+ / Docker Compose v2
- Python 3.11+（Docker 3.12）
- Node.js 20.19+ / pnpm 9+

## 三、上线

### 1. 改配置

```bash
cd /opt/test-copilot

# .env.local — AI 密钥 + Embedding
cp youlai-fastapi-master/.env.local.example youlai-fastapi-master/.env.local
```

`.env.local` 改三项：

```env
AI_API_KEY=sk-your-key
EMBEDDING_PROVIDER=ollama
OLLAMA_BASE_URL=http://<外部Ollama-IP>:11434
OLLAMA_EMBEDDING_MODEL=bge-m3      # 或 text-embedding-v3
EMBEDDING_DIM=1024
```

### 2. 建库

```bash
# 构建 ES 镜像（仅首次）
cd docker/elasticsearch && bash build.sh && cd ../..

# 启动
docker compose up -d

# 导 SQL
docker compose exec -T tc-postgres psql -U youlai -d youlai_admin \
  < youlai-fastapi-master/sql/postgresql/youlai-admin.sql
docker compose exec -T tc-postgres psql -U youlai -d youlai_admin \
  < youlai-fastapi-master/sql/postgresql/youlai-aitc.sql
```

> Milvus collection 和 ES index 不需要手动建——代码在首次索引/检索时会自动创建。

### 3. 前端

```bash
cd vue3-element-admin
pnpm install && pnpm build-only
cp -r dist/* /usr/share/nginx/html/
```

### 4. 验证

```bash
curl http://localhost:8000/health
# {"status":"ok","service":"test-copilot"}
```

## 四、Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /usr/share/nginx/html;
    index index.html;

    location /prod-api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 八、常见问题

**Q: API 报数据库连接失败**
A: `.env` 里 `DATABASE_URL` 必须用容器名 `tc-postgres`，不是 localhost。

**Q: AI 对话无响应**
A: 检查 `.env.local` 里 `AI_API_KEY`，确认 Redis 正常。

**Q: 向量检索报 dimension not match**
A: `EMBEDDING_DIM` 与 Ollama 模型输出维度不一致。bge-m3 = 1024，text-embedding-v3 = 1024，nomic-embed-text = 768。

**Q: ES 启动失败**
A: 先构建镜像：`cd docker/elasticsearch && bash build.sh`。

```bash

alembic revision --autogenerate -m "描述改动"

```

alembic 基线 `11eff7563164` 与 SQL 文件描述的真实库结构对齐。首次在已有库上启用 alembic：

```bash
alembic stamp 11eff7563164   # 标记当前库为基线
```
