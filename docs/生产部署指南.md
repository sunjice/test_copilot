# 生产部署指南

## 一、架构概览

```
客户端 ──→ Nginx (80/443) ──┬── / → 前端静态文件 (Vite build)
                            │
                            └── /prod-api/ → 后端 API (uvicorn :8000)
                                                   │
                                    ┌──────────────┼──────────────┐
                                    │              │              │
                              PostgreSQL 16    Redis 7      阿里云百炼
                              (15432)          (6379)       (AI 模型)
```

| 组件 | 端口 | 说明 |
|------|------|------|
| 前端 | 80/443 | Vite 构建产物，Nginx 托管 |
| 后端 | 8000 | FastAPI + uvicorn，4 workers |
| PostgreSQL | 15432 | 容器名 `youlai-postgres` |
| Redis | 6379 | 容器名 `youlai-redis` |

## 三、部署步骤

### 3.1 数据库初始化

```bash
# 1. 启动 PostgreSQL + Redis
cd /path/to/product_db
docker compose up -d

# 2. 等待数据库就绪（约 10 秒）
docker ps --filter "name=youlai-postgres" --filter "health=healthy"

# 3. 建表
docker exec -i youlai-postgres psql -U youlai -d youlai_admin < sql/schema.sql

# 4. 导入种子数据（用户/角色/菜单/权限/字典）
docker exec -i youlai-postgres psql -U youlai -d youlai_admin < sql/seed.sql

# 5. 验证
docker exec youlai-postgres psql -U youlai -d youlai_admin -c "SELECT count(*) FROM sys_user; SELECT count(*) FROM sys_menu;"
# 预期：sys_user=7, sys_menu=82
```

### 3.2 后端部署

#### 方式一：Docker 部署（推荐）

```bash
cd youlai-fastapi-master

# 1. 复制 AI 配置到 .env（生产环境需要单独配置 AI 服务密钥）
#    确保 .env 中 DATABASE_URL 指向 docker 内网地址：
#    postgresql+asyncpg://youlai:Youlai%402026@youlai-postgres:5432/youlai_admin
#    REDIS_URL 指向：redis://:123456@youlai-redis:6379/0

# 2. 构建镜像
docker build -t youlai-fastapi:latest .

# 3. 启动（需与 docker-compose 同网络）
docker run -d \
  --name youlai-backend \
  --network product_db_youlai-net \
  -p 8000:8000 \
  --env-file .env \
  --env-file .env.local \
  youlai-fastapi:latest

# 4. 验证
curl http://localhost:8000/health
# 预期：{"status":"ok","service":"youlai-fastapi"}
```

#### 方式二：本地运行

```bash
cd youlai-fastapi-master

# 安装依赖（推荐 uv）
pip install uv
uv sync --frozen

# 启动
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

### 3.3 前端部署

```bash
cd vue3-element-admin

# 1. 安装依赖
pnpm install

# 2. 确认生产环境配置
# 编辑 .env.production，确保包含：
#   VITE_APP_BASE_API=/prod-api
#   VITE_APP_TITLE=AITC
#   VITE_APP_TENANT_ENABLED=false
#   VITE_APP_API_URL=https://你的服务器域名  （Nginx 代理用，如果 Nginx 已配 proxy_pass 则不需要）

# 3. 构建
pnpm build

# 4. 产物在 dist/ 目录，部署到 Nginx
cp -r dist/* /usr/share/nginx/html/
```

### 3.4 Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /usr/share/nginx/html;
    index index.html;

    # API 代理到后端
    location /prod-api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 支持（AI Chat 流式响应）
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }

    # Vue Router history 模式
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 四、关键配置清单

### 4.1 后端 `.env` 必改项（生产环境）

```env
# 数据库 — 生产环境建议使用独立 PostgreSQL 实例，不要和 docker-compose 混用
DATABASE_URL=postgresql+asyncpg://youlai:你的生产密码@生产DB地址:5432/youlai_admin

# Redis
REDIS_URL=redis://:你的Redis密码@生产Redis地址:6379/0

# JWT 密钥 — 务必更换为随机生成的 64 字符字符串
JWT_SECRET_KEY=生产环境请随机生成64位字符串

# CORS — 限制为生产域名
ALLOWED_ORIGINS=https://your-domain.com

# 调试 — 生产环境关闭
DEBUG=false
LOG_LEVEL=WARNING
```

### 4.2 后端 `.env.local` AI 服务配置

```env
# 阿里云百炼 DashScope（当前使用）
AI_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
AI_MODEL=deepseek-v4-flash-0731
AI_TEMPERATURE=0.7
AI_MAX_TOKENS=4096
```

### 4.3 前端 `.env.production`

```env
VITE_APP_BASE_API=/prod-api
VITE_APP_TITLE=AITC
VITE_APP_TENANT_ENABLED=false
# 如果 Nginx 已配置 proxy_pass，以下两行不需要
# VITE_APP_API_URL=https://your-domain.com
# VITE_APP_PORT=443
```

## 八、常见问题

**Q: 后端启动报 `ModuleNotFoundError: app.system.product`**
A: product 模块已在清理中删除。确认 `app/main.py` 和 `app/registry.py` 中无 product 相关 import。如果用的是旧镜像，需重新构建。

**Q: 前端页面空白/404**
A: 检查 Nginx 是否配置了 `try_files $uri /index.html`。检查 `.env.production` 中 `VITE_APP_BASE_API=/prod-api` 与 Nginx `location /prod-api/` 是否匹配。

**Q: AI 对话无响应**
A: 检查 `.env.local` 中 `AI_API_KEY` 是否有效、`AI_API_BASE` 是否可达。确认 Redis 正常运行（AI 任务调度依赖 Redis 分布式锁）。

**Q: 数据库连接失败**
A: 确认 `DATABASE_URL` 中主机名与容器网络匹配。Docker 内部用容器名（`youlai-postgres`），宿主机用 `localhost`。
